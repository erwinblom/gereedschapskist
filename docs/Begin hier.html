Voor je begint: openen en bewaren

Je kunt je werk bewaren en een volgende keer verdergaan. Klik in de tool bovenaan op Bewaar bestand. Het bestand komt meestal in Downloads terecht. Open later dezelfde tool en kies via Bestand openen je laatst bewaarde bestand. Bewaar opnieuw na wijzigingen.

De acht administratieve tools bewaren hun hele verzameling in een .json-bestand. Schrijven bewaart het geopende document als .md-bestand. Je hoeft deze bestanden niet zelf te bewerken. Browseropslag is alleen tussentijds; je eigen bestand is je back-up.

Online: open een tool op deze website. Offline: pak de volledige ZIP uit en open Begin hier.html. Beide versies gebruiken dezelfde gegevensbestanden. Er is geen automatische synchronisatie. Bewaar je bestand in de ene versie en open het in de andere.

Gebruik Chrome of Edge op je computer. Met de terugknop van je browser kom je terug in dit overzicht. Bewaar de uitgepakte map bij elkaar.

Schrijven: open een Markdown-bestand of begin met een nieuw document. Via Project toevoegen kun je ook een eigen map kiezen als je browser en organisatie dit toestaan. Gebruik Bewaar document voor een bestand op je computer.

De overige apps: gebruik de bewaarknop voor een gegevensbestand en bewaar dat op een herkenbare plek buiten de appmap. Browseropslag is alleen een tussentijdse kopie. Maak zelf een back-up.

De apps werken afzonderlijk. In Offreren en Factureren kun je gegevens uit je contactenbestand overnemen. Factureren kent bij definitief maken een vast factuurnummer toe. Bewaar daarna je actuele gegevensbestand.

Je werk blijft op je computer. Bewaar zelf je bestanden.
